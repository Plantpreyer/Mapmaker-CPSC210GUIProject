# *My Personal Project*

My personal project will be a map software where users can create their own maps with mountains, trees, trails, buildings, etc, save them, export them to various file formats, etc. This can be used by **writers**, **role-playing games**, **hikers**, **architects**, or anyone else who needs a highly customizable map. This project is of interest to me because I've had to look for various map softwares to print trails for hikes and I think it would be interesting to try and create one, especially one where you can design your own landscapes.
